# BTC Global Trading — Android (ทดสอบ)

ดาวน์โหลดแอปเวอร์ชันล่าสุด: **[BTC-Global-Trading.apk](https://github.com/black7ks/btc-global-trading-android/releases/latest/download/BTC-Global-Trading.apk)**

วิธีติดตั้ง
1. กดลิงก์ด้านบนบนมือถือ Android แล้วดาวน์โหลดไฟล์
2. เปิดไฟล์ ถ้ามีข้อความเตือน "แอปจากแหล่งที่ไม่รู้จัก" ให้กด อนุญาต / ติดตั้งต่อ
3. เวอร์ชันใหม่ใช้ลิงก์เดิม กดโหลดแล้วติดตั้งทับได้เลย

รองรับมือถือ Android 64-bit (เครื่องเกือบทั้งหมดตั้งแต่ปี 2017) รวมถึงจอพับ Galaxy Z Fold
